# Programming Street - 150

A curated collection of **150 programming problems** designed to build strong programming fundamentals, logical thinking, and problem-solving skills before diving into advanced Data Structures and Algorithms (DSA).

This repository provides a structured learning path for beginners, starting from basic programming concepts and gradually progressing toward intermediate and advanced problems.

---

## 🎯 About the Repository

**Programming Street - 150** focuses on developing the core skills required to become a confident programmer.

Instead of jumping directly into complex DSA concepts, this repository emphasizes:

- Programming fundamentals
- Logical thinking
- Problem-solving
- Mathematical reasoning
- Pattern-based problems
- Algorithmic thinking
- Writing clean and structured code

The problems are organized into **three progressive sprints**, allowing learners to gradually increase their problem-solving ability.

---

## 🛣️ Learning Path

### 🟢 Sprint-1 — Fundamentals

Focuses on basic programming concepts and logic building.

Topics include:

- Variables & Data Types
- Operators
- Conditional Statements
- Loops
- Basic Mathematical Problems
- Number-Based Problems
- Basic Pattern Problems

---

### 🟡 Sprint-2 — Intermediate

Builds upon fundamental concepts and introduces more challenging problem-solving techniques.

Topics include:

- Mathematical & Logical Problems
- Number Manipulation
- Pattern Problems
- String Basics
- Nested Loops
- Intermediate Problem Solving
- Optimization of Basic Solutions

---

### 🔴 Sprint-3 — Advanced Foundations

Focuses on strengthening problem-solving skills through more challenging programming problems.

Topics include:

- Advanced Logical Problems
- Complex Mathematical Problems
- Advanced Patterns
- String Manipulation
- Algorithmic Thinking
- Optimization Techniques
- Challenging Problem-Solving Exercises
